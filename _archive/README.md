# Archived myths

These myths are not shown on the site because no academic study supporting their answer has been added yet. The site only publishes a myth once a peer-reviewed study or scholarly book answers it, and the short answer summarizes what that research finds.

To bring a myth back once it has a supporting study:

1. Move its file from `_archive/myths/` back to `_myths/`.
2. Move its evidence files (they start with the myth's ID) from `_archive/evidence/` back to `_evidence/`, and add the new study.
3. Run `KIND=refresh-form python3 .github/scripts/issue_to_file.py` so the "Add evidence" form lists it again.
